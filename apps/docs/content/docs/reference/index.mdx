## Machine-readable

- [`/llms.txt`](/llms.txt) lists every page with its description; [`/llms-full.txt`](/llms-full.txt) holds the
  whole documentation as plain text, for AI assistants and agents.
- Every page is also available as Markdown at `/llms.mdx/docs/...`, for example
  [`/llms.mdx/docs/guides/quickstart`](/llms.mdx/docs/guides/quickstart).
- A running instance describes its own HTTP API: `dr.openapi()` returns an OpenAPI 3.1 document of every core and
  plugin operation, and `better-files openapi` writes it to a file.
