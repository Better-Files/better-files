A permission entry gives a group or a person a set of capabilities on a folder or document, inherited by
everything under it. Bits 0 to 15 belong to the core; plugins and configuration register their own from bit 16.

## Capabilities

| Capability | Bit | Meaning |
| --- | --- | --- |
| `LIST` | 0 | See that the node exists: its name, index number and position in the tree. |
| `VIEW` | 1 | Open it in the secure viewer (server-rendered, watermarked pages). |
| `PRINT` | 2 | Print from the viewer. |
| `COPY_TEXT` | 3 | Select and copy text in the viewer. |
| `DOWNLOAD_WATERMARKED` | 4 | Download a copy watermarked for the person downloading it. |
| `DOWNLOAD_ORIGINAL` | 5 | Download the original file. |
| `UPLOAD` | 6 | Add children to a folder, or new versions to a document. |
| `EDIT` | 7 | Rename, move and change metadata; see earlier versions of a document. |
| `DELETE` | 8 | Move to the trash and restore. |
| `MANAGE` | 9 | Permissions, members and settings for the subtree. |

## Presets

Presets are named capability sets for permission entries and groups (`preset: 'view'`). Add your own with the `capabilities.presets` option.

| Preset | Capabilities |
| --- | --- |
| `hidden` | none (hidden) |
| `view` | `LIST`, `VIEW` |
| `viewPrint` | `LIST`, `VIEW`, `PRINT` |
| `download` | `LIST`, `VIEW`, `PRINT`, `DOWNLOAD_WATERMARKED` |
| `downloadOriginal` | `LIST`, `VIEW`, `PRINT`, `COPY_TEXT`, `DOWNLOAD_WATERMARKED`, `DOWNLOAD_ORIGINAL` |
| `contributor` | `LIST`, `VIEW`, `PRINT`, `DOWNLOAD_WATERMARKED`, `UPLOAD` |
| `editor` | `LIST`, `VIEW`, `PRINT`, `DOWNLOAD_WATERMARKED`, `UPLOAD`, `EDIT`, `DELETE` |
| `manager` | all |
