Every API throws `BetterFilesError`, with a stable `code`, an HTTP `status`, a message, and optional
`details`. Over HTTP the body is `{ "error": { "code", "message", "details"? } }`, and the typed client throws the
same codes. Check codes with `isBetterFilesError(error)` and `error.code`, never the message.

| Code | Status | Meaning |
| --- | --- | --- |
| `INVALID_CONFIG` | 500 | The instance or a plugin is misconfigured. Thrown when `betterFiles()` builds or initializes, never for user input. |
| `INVALID_INPUT` | 400 | The input failed validation, or names something impossible (a folder moved into itself). `details` lists the issues. |
| `UNAUTHENTICATED` | 401 | No valid credential. Sign the person in, or pass the session token or cookie. |
| `FORBIDDEN` | 403 | The identity system or the permission matrix refused the operation, or a plugin gate (an unaccepted NDA) did. |
| `NOT_FOUND` | 404 | The thing does not exist for this caller. Items without the `LIST` capability are reported as not found. |
| `CONFLICT` | 409 | The state does not allow it: a duplicate name, publishing a live room, deleting a room that is not archived. |
| `ROOM_CLOSED` | 409 | The room is closed or archived, so content cannot change. Reopen it first. |
| `NDA_REQUIRED` | 403 | The room requires accepting its NDA before this. Show the NDA and call `nda.accept`. |
| `MFA_REQUIRED` | 403 | The room requires multi-factor authentication for this (downloads). Step the person up and retry. |
| `QUARANTINED` | 409 | The file is still being scanned or processed, or the scanner flagged it. |
| `LEGAL_HOLD` | 409 | A legal hold or retention rule keeps this content: it cannot be deleted, purged or moved out of the hold. |
| `QUOTA_EXCEEDED` | 429 | A byte, document or file-size quota of the room or tenant would be exceeded. |
| `RATE_LIMITED` | 429 | Too many requests from this identity, room or link. Retry later. |
| `PAYLOAD_TOO_LARGE` | 413 | The request body or the file is larger than the configured limit. |
| `UNSUPPORTED` | 501 | The adapter or plugin does not support this (direct uploads on a store without presigned parts). |
| `INTERNAL_ERROR` | 500 | An unexpected failure. The server logs it; the response carries no details. |
